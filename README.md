IT Service Desk and SLA Performance Analytics

Project Overview

The IT Service Desk and SLA Performance Analytics project focuses on analysing IT support ticket data using MySQL 8.0.

The project analyses support tickets raised by employees and customers for incidents, system failures, access requests and technical issues.

The main objective is to evaluate ticket volumes, resolution performance, SLA compliance, support team performance and ticket backlogs.

Business Objectives

- Analyse total tickets received.
- Identify resolved, open, pending and closed tickets.
- Analyse ticket volume by priority.
- Calculate average ticket resolution time.
- Identify SLA-breached tickets.
- Calculate SLA breach percentage.
- Identify support teams with the highest backlog.
- Analyse reopened tickets.
- Track monthly ticket trends.

Dataset Description

The project uses five datasets:

1. Customers: Customer information and locations.
2. Support Teams: Support team details.
3. Tickets: Ticket information, priorities, statuses and timestamps.
4. SLA Rules: Priority-wise resolution time targets.
5. Ticket History: Ticket status changes and reopened records.

Business Insights

This project helps management understand ticket resolution efficiency, identify teams with higher backlogs, monitor SLA performance, analyse reopened tickets and identify operational improvement opportunities.

Project Outcome

Developed SQL-based operational reports to analyse IT service desk performance, monitor SLA compliance and evaluate support team efficiency.
